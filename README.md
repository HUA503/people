## 安装方式 / Installation

### 方式 1：安装到 Agent Skills 全局目录（推荐）

```bash
# 通用 AgentSkills / Codex / Antigravity 目录
git clone https://github.com/HUA503/people.git ~/.agents/skills/wu-junjin

# 或 Claude Code 全局目录
git clone https://github.com/HUA503/people.git ~/.claude/skills/wu-junjin
```

### 方式 2：作为子模块或文件夹引入项目

将 `wu-junjin` 文件夹复制到你项目的 `.agents/skills/` 或 `.claude/skills/` 目录下即可。
